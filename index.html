Нужно настроить Supabase

Заполните config.js рядом с index.html. Авторизация не используется — доступ регулируется RLS-политиками Supabase:

window.ROADMAP_CONFIG = { supabaseUrl: "https://PROJECT.supabase.co", supabaseKey: "sb_publishable_...", roadmapId: "main" };

После этого перезагрузите страницу.
